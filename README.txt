SETUP
1. Install Android Studio (latest), File > Open > select the CallRecorder folder.
2. Wait for Gradle sync (needs internet the first time).
3. On phone: Settings > About phone > tap Build number 7 times; then
   Developer options > turn on USB debugging. Connect phone by USB.
4. Press the green Run button in Android Studio (or Build > Build APK(s) and install the APK).
5. Open the app and do steps 1, 2, 3 on screen, keep "Auto-record calls" ON.
6. Make a test call, use SPEAKER so the other person is recorded.
7. Files: Files app > Recordings > CallRecords.
